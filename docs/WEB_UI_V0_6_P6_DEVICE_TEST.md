## 注意
GitHub Pages は同一リポジトリで通常は本番配信先が1つ。featureブランチから `actions/deploy-pages` で上書きしない。
このブランチの `web-ui-check.yml` は成果物をZIPアーティファクトとして保存するだけで、本番 `main` に影響しない。

テスト版URLには、本番とは **異なるオリジン** を使用する。ブラウザの localStorage / IndexedDB などは独立したセーブとして扱う。
新しいドメインで本番の保存状態が自動で復元されると想定しない。通常プレイ中の本番 Safari データは消さない。

## P6-C iPhone実機チェックリスト
1. Safariで専用ステージングURLを開く（**本番URLではないことを確認**）。
2. 縦持ちで回転案内がある。横持ち左右反転でもUIが隠れない。
3. 戦闘: 敵1～3、Intent、HP/Mana/Block、手札5枚、手札6枚以上の横スワイプ。
4. カード: 1回目で選択・詳細、敵タップで攻撃、自分対象は2回タップ。キャンセルでMana不変。
5. 拠点: 6装備、4カード・特殊効果の詳細、鍛冶、購入・売却・分解を誤決定しない。
6. 宝箱/報酬: 1回目は詳細のみ、同じ候補2回目で取得。スキップも同様。
7. 道・イベント・休憩: 2回目で決定。費用は重複しない。
8. 敗北: 装備詳細・確保上限・帰還確定。保存して再起動。
9. Chromeの擬似画面結果と異なる箇所はiPhone Safariスクリーンショットで記録。
